# MangaBox 📚

کمیک‌خوان آفلاین و فارسی برای اندروید (Flutter). فرمت‌ها: **CBZ / CBR (RAR4) / PDF** — فونت: Waw

## ساخت APK با GitHub Actions
بعد از push روی شاخه‌ی `main`، تب **Actions** خودکار بیلد می‌گیرد؛ فایل APK در پایین همان اجرا، بخش **Artifacts** (`mangabox-apk`) است. روی بیشتر گوشی‌ها `arm64-v8a`.
- Release خودکار: `git tag v2.0.0 && git push origin v2.0.0`
- همه‌ی بیلدها با یک کلید ثابت (`tool/debug.keystore`) امضا می‌شوند؛ پس APK جدید روی قبلی نصب می‌شود (فقط برای استفاده‌ی شخصی؛ برای انتشار عمومی کلید خودتان را بسازید).

## منطق برنامه
```
Dart (رابط + کتابخانه)          Kotlin (موتور)
────────────────────           ─────────────────────────────
LibraryPage / ReaderPage  ⇄    ComicEngine
LibraryStore (library.json)      • ZIP/CBZ  → java.util.zip.ZipFile
PageCache (LRU بایت)             • PDF      → android.graphics.pdf.PdfRenderer
                                 • content:// → fd مستقیم، وگرنه کپی موقت در cache
```
۱. **افزودن:** با انتخاب‌گر سیستم (SAF) فایل/پوشه انتخاب می‌شود؛ فقط آدرس ذخیره می‌شود (کپی نمی‌شود).
۲. **باز کردن:** Dart می‌گوید «این آدرس را باز کن» ← Kotlin فرمت را از بایت‌های ابتدای فایل تشخیص می‌دهد ← تعداد صفحه‌ها را می‌دهد. هر صفحه با درخواست جداگانه می‌آید.
۳. **فایل از تلگرام/فایل‌منیجر:** اگر اندروید دسترسی ماندگار ندهد، فایل یک‌بار در حافظه‌ی داخلی اپ کپی می‌شود تا بعد از بستن برنامه هم در کتابخانه بماند (با حذف از کتابخانه، کپی هم پاک می‌شود).
۴. **حافظه:** PageCache فقط بایت‌های فشرده را تا ۸۰MB نگه می‌دارد؛ دیکد فقط تا عرض لازم انجام می‌شود. ۳ صفحه‌ی بعد و ۱ صفحه‌ی قبل پیش‌بارگذاری می‌شود.
۵. **پیشرفت:** صفحه‌ی آخر، درصد و زمان با تأخیر ۶۰۰ms و همچنین هنگام رفتن به پس‌زمینه ذخیره می‌شود.
۶. **کتابخانه:** جستجو در نام (با یکسان‌سازی «ي/ك» و ارقام فارسی/عربی)، فیلتر همه / در حال خواندن / تمام‌شده / خوانده‌نشده (با شمارنده)، و مرتب‌سازی (آخرین مطالعه، تازه‌ترین افزوده‌شده، نام، بیشترین پیشرفت) که ذخیره می‌شود.
۷. **زوم هوشمند پنل:** در حالت ورق‌زدن، دابل‌تپ روی هر پنل همان پنل را تمام‌صفحه می‌کند؛ دابل‌تپ دوباره برمی‌گرداند. پنل‌ها با برش بازگشتی روی «فاصله‌ی خالی بین پنل‌ها» (XY-cut) از نسخه‌ی کوچک صفحه تشخیص داده می‌شوند و برای هر صفحه یک‌بار حساب و نگه‌داری می‌شود. با دکمه‌ی ✨ نوار بالا خاموش/روشن می‌شود.
۸. **دو صفحه‌ای:** وقتی گوشی افقی است (ورق‌زدن چپ‌به‌راست یا مانگا)، دو صفحه کنار هم نشان داده می‌شود (در مانگا ترتیب برعکس). با گزینه‌ی «صفحه‌ی اول تنها» جلد جدا می‌ماند و بقیه جفت می‌شوند (۱-۲، ۳-۴، …). از آیکون کتاب باز در نوار بالا (فقط در حالت افقی) روشن/خاموش می‌شود. چرخش گوشی خودکار بین تک‌صفحه‌ای و دو صفحه‌ای جابه‌جا می‌شود و صفحه‌ی فعلی حفظ می‌شود. در این حالت دابل‌تپ زوم ساده‌ی ۲٫۲× است (زوم هوشمند پنل فقط برای تک‌صفحه‌ای).
۹. **خواندن:** ورق‌زدن افقی، مانگا (راست‌به‌چپ)، وبتون؛ دابل‌تپ برای زوم؛ تپ وسط برای منوها (حالت Immersive)؛ نوار پیمایش با پیش‌نمایش صفحه؛ قفل چرخش.

## محدودیت‌های فعلی (صادقانه)
- **CBR:** RAR نسخه‌ی ۴ (و قدیمی‌تر) پشتیبانی می‌شود؛ **RAR5** با junrar ممکن نیست و پیام فارسی می‌دهد (CBR که در اصل ZIP است بدون مشکل باز می‌شود). RAR یک‌بار کامل در cache استخراج می‌شود (فقط ۲ کمیک آخر نگه داشته می‌شود)، پس باز شدن اول CBR حجیم چند ثانیه طول می‌کشد.
- زوم وبتون: پینچ دو انگشتی (تا ۴×) و دابل‌تپ؛ نقطه‌ی زوم فقط در راستای افقی دقیقاً زیر انگشت می‌ماند (در راستای عمودی نزدیک به بالای صفحه).
- **زوم هوشمند:** فقط برای صفحه‌هایی که پنل‌هایشان با فاصله‌ی روشن/تیره از هم جدا شده‌اند خوب کار می‌کند. طرح‌های مورب، هم‌پوشان یا تمام‌صفحه به زوم ساده (پر کردن صفحه) برمی‌گردند.
- **دو صفحه‌ای:** جفت‌سازی ثابت است (صفحه‌هایی که خودشان دو صفحه‌ی باز کنار هم‌اند جدا تشخیص داده نمی‌شوند)؛ اگر جفت‌ها جابه‌جا افتاد، «صفحه‌ی اول تنها» را خاموش/روشن کنید.
- فقط اندروید.
